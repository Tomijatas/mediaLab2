# mediaLab2

This lab aims to build your first Virtual Reality (VR) application using A-Frame.

---

## Tested on these browsers

The application was fully tested and works correctly on:

* Brave v1.89.132 (Chromium 174.0.7727.56)
* Microsoft Edge v147.0.3912.60

---

## Features implemented

The following interactive features were implemented:

* Rotate object
* Move (shift) object
* Zoom in / Zoom out
* Load different object (switch between models)

---

## Requirements for repository

* The repository contains two branches: **master** and **develop**
* All new features were implemented and committed in the **develop** branch
* Final version was merged into the **master** branch

---

## Requirements for VR application

* Updated A-Frame to a newer version
* Used point cloud component
* Reduced scene to a single model
* Customized environment (sky/background)
* Implemented interactive control panel with multiple features

---

## Important notes

* The application requires a local web server to run correctly
* Tested using Live Server extension in Visual Studio Code

Alternative servers:

* Apache
* Tomcat
* HFS
